## 8. Software Licensing and Renewal Policy

- All licensed software must be procured through the IT Procurement Team.  
- Renewals are tracked automatically in the IT Asset Management (ITAM) system.  
- Vendors are notified 30 days before license expiration.  
- Unauthorized or unapproved software installation is strictly prohibited.  
- License audits are conducted bi-annually to ensure compliance.  
- Cloud applications follow enterprise single sign-on (SSO) policy for access control.  
- End-of-life software is decommissioned or replaced with supported versions.
